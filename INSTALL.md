# CMD/Terminal
1. Download as ZIP
2. Unzip into a directory so that there is a directory named `final_project_s1_y1` containing the source code.
3. Change working directory to the parent of `final_project_s1_y1`.
4. Invoke through `python3 -m final_project_s1_y1`. Python >= 3.12

# IDLE
1. Perform steps 1 & 2 above.
2. Open IDLE in working directory
3. Execute `from final_project_s1_y1 import main`
4. Execute `main()`
